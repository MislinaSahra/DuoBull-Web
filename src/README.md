# `src` Kaynak Kodu

Bu klasör çalışan web uygulamasının düzenlenebilir kaynak kodudur. Üretilmiş veya gizlenmiş uygulama implementation'ı yoktur.

- Yeni URL veya sayfa: `app/AppRoutes.jsx` + `pages/`
- Ortak görünüm: `components/`
- Uygulama state'i: `context/`
- Supabase işlemleri: `services/`
- Sabit metin/veri: `data/` ve `constants/`
- Global stil: `styles.css`
- Tarayıcı giriş noktası: `main.jsx`

Bir ekrandaki metni bulmanın en hızlı yolu VS Code `Ctrl+Shift+F` ile metni doğrudan aramaktır.
